# Stand-up, 2026-11-26

## Done since the last check-in (2026-11-25)

**Release**
- **0.5.0 merged into `main`** (abdallahtahboub/Testo#89), the first release; it becomes official when the owner tags
  `v0.5.0`. The release pull request's CI caught a real fault: self-refreshing test and run pages could end their session
  when a save met a refresh. It was fixed with one data call at a time per page (abdallahtahboub/Testo#88).

**Explorer and safety**
- **Guarded pressing (Milestone 5.1 R8, ADR-0041, #91):** a site exploring may not act on has its buttons, tabs and
  links pressed with every write blocked. Its own tests found a leak: the browser let a polling page's POST through while
  it navigated. The egress proxy now refuses writes too, on http (#93); **R-23 stays open for https**.
- **Client-side applications (ADR-0021 amendment, #93):** fragment routes are pages, a page is read once drawn, and
  exploring stops in time instead of returning nothing. OWASP Juice Shop went from 24% to 68% read-only and from 0% to
  74% acting.
- **Stronger locators (ADR-0042, #96):**
  - a field can be named by its label;
  - `menuitem` and `tab` are roles a target may name;
  - landmarks, dialogs and named regions are containers;
  - a chosen locator must find the element described, which fixed an older flaw.

  Password fields were wrongly said to have no role; this is corrected.
- **Product defects fixed:**
  - the egress proxy judged only the first request on a kept-open connection (R-22);
  - a refused WebSocket counted as an unreachable site;
  - the browser guard leaked (R-23, mitigated);
  - the explorer's waiting made CI outgrow its limit;
  - a locator could be credited to the wrong element.

**Measurement (Milestone 5.1 R9, free part; `docs/reviews/2026-11-25-r9-juice-shop.md`)**
- **OWASP Juice Shop (tuning):** 9 scenarios with passing baselines; coverage 74% acting, 68% read-only, 74% guarded.
- **Gitea (clean):** 9 baselines pass; coverage 73%, 68%, 68%; nothing tuned on it (#94, #95).
- **Our three applications:** no figure fell through any of these changes (#97).
