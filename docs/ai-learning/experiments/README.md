# Experiments

Every learning experiment gets one file here, **written before it runs** and completed after, whatever the outcome.
Failed experiments and negative results stay: they are findings.

## The template

```markdown
# NNNN — Title

- Status: Designed | Approved | Running | Reported
- Designed: YYYY-MM-DD   Reported: YYYY-MM-DD

## Hypothesis (pre-registered)
## Baseline and conditions
## Data: scenarios, applications, faults, splits, dataset version
## Procedure
## Verification: where ground truth comes from
## Metrics, success threshold, failure conditions (pre-registered)
## Configuration: model id, prompt hash, explorer/validator commit, retrieval settings
## Estimated cost   /   Actual cost
## Security requirements
## Results (as measured, linked to the raw reports)
## Limitations
## Decision that follows
```
